Hyperteen: Youth Hypertension Risk Detector & Healthcare System

Tentang Proyek :
Hyperteen adalah prototipe sistem pelacakan kesehatan multi-tier yang dirancang khusus untuk membantu anak muda mendeteksi risiko hipertensi sejak dini melalui pemantauan pola hidup dan kondisi fisik secara terstruktur.

Proyek ini awalnya dikembangkan untuk kompetisi tingkat nasional. Dalam proyek tim ini, saya bertindak sebagai Lead Backend Developer yang bertanggung jawab penuh atas perancangan arsitektur sistem dan implementasi kode dari awal hingga akhir.

Fitur Utama
  Hypertension Risk Detection: Algoritma pemrosesan logika (rule-based) untuk menganalisis indikator kesehatan dan mendeteksi potensi risiko hipertensi sejak dini.
  Heart Tracker: Pemantauan dan pencatatan detak jantung pengguna secara berkala.
  Sleep Tracker: Pelacakan durasi dan pola tidur untuk menjaga kestabilan tekanan darah.
  AI Food Scanner: Pemindaian makanan secara cerdas untuk membantu pengguna mengontrol asupan nutrisi dan sodium harian.
  Health Insights: Analisis ringkasan data harian dan rekomendasi gaya hidup sehat bagi pengguna.

Arsitektur & Teknologi
  Backend: Java (Spring Boot)
  Arsitektur: Model-View-Controller (MVC)
  Database: MySQL
  Logika Sistem: Rule-Based Algorithm
